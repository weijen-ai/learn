Unit 26：Can, could and be able to

學習 can、could 與 be able to 表達能力、可能性與許可，並掌握「過去一般能力」和「某次具體情況中成功做到」的關鍵差別。

2026-09-06 AI-assisted study guide, grounded in: 使用者提供的英文文法教材照片：Unit 26, “Can, could and be able to” · 第 52–53 頁；Unit 26；Exercises 26.1–26.5

Learning objectives

  • 正確使用 can + 原形動詞表達現在的能力或可能性。
  • 說明為何 can 後面不能接 to。
  • 在需要不同時態或情態動詞時使用 be able to。
  • 區分 could 的過去一般能力與 was/were able to、managed to 的一次成功結果。
  • 在過去否定情況中正確使用 couldn’t。

Explanation, step by step

核心概念：can 後面接什麼？

can 用來表達現在的能力、可能性或許可。

句型：can + 原形動詞
- I can run fast.（我跑得快。）
- Can you speak Spanish?（你會說西班牙語嗎？）
- The restaurant can be very noisy.（那間餐廳可能很吵。）

不要說：can to run 或 can to speak。can 後面直接接動詞原形。

為什麼需要 be able to？

can 只有 can（現在）和 could（過去）兩個形式。當句子需要完成式、未來式，或搭配其他情態動詞時，改用 be able to。

  • I haven't been able to sleep recently.（我最近一直沒能睡好。）
  • Applicants must be able to speak two foreign languages.（申請者必須能說兩種外語。）
  • She might be able to help you.（她或許能幫你。）

把 be 隨主詞和時態變化：am/is/are able to、was/were able to、have been able to、will be able to。

could：過去的一般能力與感官

could 可表示過去的一般能力或許可。
- My grandfather could speak five languages.（我祖父會說五種語言。）
- We could do what we wanted.（我們可以做想做的事。）

could 特別常搭配感官與理解動詞：see, hear, smell, taste, feel, remember, understand。
- We could see the lake.
- I could smell gas.
- I couldn't hear very well.

這類句子描述當時能否感知或理解，因此 could / couldn't 很自然。

特定一次成功：was/were able to 或 managed to

要表達某人在某個具體情境中真的成功完成了事情，使用 was/were able to 或 managed to，通常不使用 could 的肯定句。

  • Everybody was able to escape.（每個人都成功逃出。）
  • We managed to find David in the end.（我們最後成功找到 David。）
  • Jack managed to beat Andy.（Jack 這一次成功打敗 Andy。）

managed to 常帶有「經過困難、努力後終於成功」的語氣。

否定句的重要規則

couldn't 可用於過去任何「未能做到」的情況，包括具體事件。
- We looked everywhere, but we couldn't find him.
- I couldn't sleep last night.
- Andy couldn't beat Jack.

因此可先記住：
- 過去肯定、一次成功 → was/were able to 或 managed to
- 過去否定、做不到 → couldn't 很常用

快速選擇法

遇到空格時依序問：
- 是現在能力或可能性嗎？→ can / can't
- 是過去的一般能力或感官嗎？→ could / couldn't
- 是過去某一次成功完成嗎？→ was/were able to 或 managed to
- 需要 have, might, must, will 等其他形式嗎？→ be able to

例：She might be able to help you. 不能說 She might can help you.

自我練習：把文法連到生活

試著用自己的經驗完成這些問題：
- What could you do well when you were younger?
- What would you like to be able to do?
- What have you never been able to do?

回答時注意：一般的童年能力用 could；想在未來學會的能力可用 would like to be able to；到現在仍未成功的事可用 have never been able to。

Flashcards

Answer in your head, then reveal.

can 後面要接什麼形式？

Show answer

動詞原形：can + verb。例如 can swim；不能說 can to swim。

can 有哪兩種基本形式？

Show answer

can（現在）與 could（過去）。

何時需要使用 be able to？

Show answer

當需要 can 沒有的時態或形式，例如 have been able to、will be able to、might be able to、must be able to。

could 的主要用途之一是什麼？

Show answer

表達過去的一般能力，例如 My grandfather could speak five languages.

過去感官動詞常可搭配什麼？

Show answer

could / couldn't，例如 could see、could smell、couldn't hear。

要說某人在一次特定事件中成功逃出，應用什麼？

Show answer

was/were able to escape 或 managed to escape。

managed to 帶有什麼額外語氣？

Show answer

經過困難、努力後終於成功。

過去某次找不到人，能用 couldn't find 嗎？

Show answer

可以。couldn't 可用於過去各種無法做到的否定情況。
