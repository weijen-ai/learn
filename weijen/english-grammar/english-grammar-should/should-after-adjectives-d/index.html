英文文法 · English Grammar：Should 的常見用法

Should 的 D、E、F：形容詞反應與條件句

延續 Section D 的形容詞反應用法，加入 E 的 if + should 條件句，以及 F 的 should 倒裝條件句。共保留 D 的 20 個例句，另加 E、F 各 5 句，並比較三種 should 的意思與句型。

Learning objectives

  • 掌握 Section D：形容詞後 that 子句中的反應用法 should。
  • 辨認並正確使用 should + 動詞原形。
  • 理解 Section E 的 if + 主詞 + should + 原形，表達較低可能性的條件。
  • 將 if + 主詞 + should + 原形轉成 Section F 的 Should + 主詞 + 原形倒裝句。
  • 分辨條件倒裝句與真正的 should 疑問句。
  • 透過 30 個例句練習 D、E、F 三個範圍。

Explanation, step by step

1. D：形容詞後的反應用法

本課只處理教材圖片的 Section D、E、F。先回顧 D：某些形容詞後的 that 子句可以用 should，表達說話者覺得事情奇怪、意外、有趣或自然。圖片列出的形容詞包括 strange, odd, funny, typical, natural, interesting, surprised, 和 surprising。

課本例句包括 It’s strange that he should be late.、I was surprised that he should say such a thing. 這裡的 should 不是「他應該遲到」，而是說話者對那件事的反應。

句型：It + be + adjective + that + 主詞 + should + 動詞原形；也可以說 I was surprised that…。should 後面用原形，例如 should be / arrive / know，不可寫 should arrives。

2. D 例句 1–10

以下是練習 D 的 10 個原創例句。可以先遮住中文，自己翻譯並找出形容詞。

  1. It’s strange that Liam should arrive before everyone else. — 奇怪的是，Liam 竟比所有人都早到。
  2. It’s odd that the café should be empty at lunchtime. — 奇怪的是，這家咖啡館午餐時間竟然空無一人。
  3. It’s funny that both sisters should choose the same song. — 有趣的是，兩姊妹竟選了同一首歌。
  4. It’s typical of Maya that she should bring snacks for everyone. — Maya 竟帶點心給大家，真是她一貫的作風。
  5. It’s natural that new students should feel nervous on the first day. — 新生第一天感到緊張是很自然的。
  6. It’s interesting that the old map should show a path through the forest. — 有意思的是，舊地圖竟標出一條穿過森林的小路。
  7. I was surprised that Daniel should remember my birthday. — 我很驚訝 Daniel 竟記得我的生日。
  8. It was surprising that the small plant should survive the winter. — 令人驚訝的是，那株小植物竟熬過了冬天。
  9. It is strange that no one should ask about the delay. — 奇怪的是，竟沒有人詢問延誤的事。
  10. It seemed odd that the lights should still be on. — 燈竟然還亮著，這看起來很奇怪。
3. D 例句 11–20
  1. I find it funny that our dog should hide whenever it rains. — 我覺得很有趣，我們家的狗每逢下雨竟然就躲起來。
  2. It’s typical of Ben that he should forget his umbrella again. — Ben 又忘了帶傘，這真的很像他的作風。
  3. It’s natural that parents should worry about their children. — 父母擔心孩子是很自然的事。
  4. It is interesting that the two teams should reach the same answer independently. — 有意思的是，兩隊竟各自得出了相同答案。
  5. I was surprised that she should refuse such a generous offer. — 她竟拒絕這麼慷慨的提議，讓我很意外。
  6. It was surprising that the old bridge should remain open after the storm. — 暴風雨後，那座舊橋竟仍然開放，令人驚訝。
  7. It’s strange that he should know the password already. — 奇怪的是，他竟已經知道密碼。
  8. It’s typical of that team that they should stay calm under pressure. — 那支隊伍在壓力下保持冷靜，真是他們一貫的作風。
  9. It is odd that the package should arrive without a label. — 奇怪的是，包裹竟然沒有標籤就送到了。
  10. I was surprised that the meeting should finish so early. — 會議竟然這麼早結束，我感到很意外。
4. D 的 should 不等於建議

比較：
- 建議：You should call her.（你應該打電話給她。）這是在勸對方做某事。
- D 的反應用法：It is strange that he should call at midnight.（奇怪的是，他竟半夜打電話來。）這是在評論一件事。

辨認技巧：D 的 should 通常出現在 It is/was + 形容詞 + that… 或 I was surprised that… 這類結構中；that 子句使用 should + 動詞原形。

5. E：If + 主詞 + should + 動詞原形

E 用 if + 主詞 + should + 動詞原形 描寫一個可能發生、但說話者覺得機率較低或想審慎提出的情況。它常用於較正式或委婉的條件句；should 不表示「應該」。

教材例句的意思是「如果情況有變，我們會聯絡你」。對照：If the situation changes, we will contact you.（一般條件）／If the situation should change, we will contact you.（把這種可能性說得較低、較審慎）。should 後仍接原形動詞。

5 個新例句：
1. If it should rain tomorrow, we’ll move the picnic indoors. — 如果明天萬一下雨，我們就把野餐移到室內。
2. If you should need extra time, please let me know. — 如果你萬一需要多一點時間，請告訴我。
3. If anyone should ask for me, say I’m in a meeting. — 如果有人找我，就說我在開會。
4. If the train should be delayed, we’ll send an update. — 如果火車萬一誤點，我們會發送最新消息。
5. If our plans should change, I’ll message you. — 如果我們的計畫有變，我會傳訊息給你。

6. F：Should + 主詞 + 動詞原形（條件倒裝）

F 把 E 的 if 子句改成倒裝：移除 if，把 should 放到主詞前面。

If + 主詞 + should + 動詞原形, 主句 → Should + 主詞 + 動詞原形, 主句

例如：If the situation should change, we will contact you. → Should the situation change, we will contact you. 兩句的條件意思相同；第二句較正式、精簡。這種句子通常不是問句，後面接逗號和主句。

5 個新例句：
1. Should it rain tomorrow, we’ll move the picnic indoors. — 如果明天萬一下雨，我們就把野餐移到室內。
2. Should you need extra time, please let me know. — 如果你萬一需要多一點時間，請告訴我。
3. Should anyone ask for me, say I’m in a meeting. — 如果有人找我，就說我在開會。
4. Should the train be delayed, we’ll send an update. — 如果火車萬一誤點，我們會發送最新消息。
5. Should our plans change, I’ll message you. — 如果我們的計畫有變，我會傳訊息給你。

7. E 和 F 對照；小心別看成問句

E 和 F 表達同一類條件，F 是較正式的倒裝版本：
- E：If you should need any help, call me.
- F：Should you need any help, call me.

F 的條件子句雖然以 should 開頭，但不是問句；看它後面是否接逗號及另一個主句。真正的疑問句 Should I call her? 是在問「我該打給她嗎？」；這和條件句 Should I need help, I’ll call her.（如果我萬一需要幫忙，我會打給她。）不同。

最後檢查：E 有 if，語序是主詞 + should；F 沒有 if，語序是 should + 主詞。兩種條件句的 should 後都接動詞原形。

Flashcards

Answer in your head, then reveal.

D：It is strange that he should be late. 裡的 should 表達什麼？

Show answer

說話者覺得「他遲到」很奇怪；不是建議他遲到。

D：should 後面的動詞用什麼形式？

Show answer

動詞原形：should be、should arrive、should know。

E 的基本結構是什麼？

Show answer

If + 主詞 + should + 動詞原形, 主句；用來提出較低機率或較審慎的可能條件。

F 如何由 E 變形？

Show answer

移除 if，把 should 移到主詞前：If it should rain… → Should it rain…

Should you need help, call me. 是問句嗎？

Show answer

不是，是條件倒裝句，等同 If you should need help, call me. 通常接逗號和主句。

Should I call her? 和 Should I need help, I’ll call her. 有何不同？

Show answer

第一句是真正的疑問句，詢問是否該打電話；第二句是條件倒裝，意為「如果我萬一需要幫忙」。

If the situation should change 和 Should the situation change 的意思有何關係？

Show answer

兩句都表示「如果情況有變」；後者是較正式的倒裝寫法。
