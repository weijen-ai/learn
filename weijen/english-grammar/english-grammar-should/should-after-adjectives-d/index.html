英文文法 · English Grammar：Should 的常見用法

Should after adjectives：形容詞後的反應用法

學習形容詞後 that 子句中的 should：它可表達說話者覺得某事奇怪、有趣、自然或意外，不是義務或建議。本教材聚焦課本 Section D，附 20 個原創例句與練習。

Learning objectives

  • 辨認 Section D 中形容詞後 that 子句的 should 用法。
  • 套用 It + be + adjective + that + subject + should + base verb 的句型。
  • 理解此處 should 表達說話者反應，不是義務或建議。
  • 正確使用 should + 動詞原形。
  • 透過 20 個原創例句熟悉常見形容詞和語境。

Explanation, step by step

1. 本課範圍：形容詞後的 should

本課只講教材圖片的 Section D：should 放在某些形容詞後面的 that 子句中。圖片列出的形容詞包括 strange, odd, funny, typical, natural, interesting, surprised, 和 surprising。

課本例句有：It’s strange that he should be late. 以及 I was surprised that he should say such a thing. 這裡的 should 帶出說話者覺得事情奇怪、出乎意料或值得注意的反應；不是「他應該遲到」或「他有義務說那件事」。

2. 句型與動詞形式

常見句型：
- It + be + adjective + that + 主詞 + should + 動詞原形
- 主詞 + be / feel / find + adjective + that + 主詞 + should + 動詞原形

例如：It is odd that she should know the answer.（奇怪的是她竟然知道答案。）

should 是情態助動詞，後面接原形：should be、should arrive、should know。不要加 to，也不要在動詞後加第三人稱單數 -s。主句可以用現在或過去式：It is surprising…、I was surprised…；that 子句裡的 should 仍接原形動詞。

3. 例句 1–10：strange、odd、funny 等

以下 10 句都是新寫的例句，練習圖片中列出的形容詞。注意每句的 should 都是在呈現說話者的反應，不是在下命令。

  1. It’s strange that Liam should arrive before everyone else. — 奇怪的是，Liam 竟比所有人都早到。
  2. It’s odd that the café should be empty at lunchtime. — 奇怪的是，這家咖啡館午餐時間竟然空無一人。
  3. It’s funny that both sisters should choose the same song. — 有趣的是，兩姊妹竟選了同一首歌。
  4. It’s typical of Maya that she should bring snacks for everyone. — Maya 竟帶點心給大家，真是她一貫的作風。
  5. It’s natural that new students should feel nervous on the first day. — 新生第一天感到緊張是很自然的。
  6. It’s interesting that the old map should show a path through the forest. — 有意思的是，舊地圖竟標出一條穿過森林的小路。
  7. I was surprised that Daniel should remember my birthday. — 我很驚訝 Daniel 竟記得我的生日。
  8. It was surprising that the small plant should survive the winter. — 令人驚訝的是，那株小植物竟熬過了冬天。
  9. It is strange that no one should ask about the delay. — 奇怪的是，竟沒有人詢問延誤的事。
  10. It seemed odd that the lights should still be on. — 燈竟然還亮著，這看起來很奇怪。
4. 例句 11–20：熟悉不同情境

再看 10 句。可以先遮住中文，自己翻譯，再檢查 should 的語氣。

  1. I find it funny that our dog should hide whenever it rains. — 我覺得很有趣，我們家的狗每逢下雨竟然就躲起來。
  2. It’s typical of Ben that he should forget his umbrella again. — Ben 又忘了帶傘，這真的很像他的作風。
  3. It’s natural that parents should worry about their children. — 父母擔心孩子是很自然的事。
  4. It is interesting that the two teams should reach the same answer independently. — 有意思的是，兩隊竟各自得出了相同答案。
  5. I was surprised that she should refuse such a generous offer. — 她竟拒絕這麼慷慨的提議，讓我很意外。
  6. It was surprising that the old bridge should remain open after the storm. — 暴風雨後，那座舊橋竟仍然開放，令人驚訝。
  7. It’s strange that he should know the password already. — 奇怪的是，他竟已經知道密碼。
  8. It’s typical of that team that they should stay calm under pressure. — 那支隊伍在壓力下保持冷靜，真是他們一貫的作風。
  9. It is odd that the package should arrive without a label. — 奇怪的是，包裹竟然沒有標籤就送到了。
  10. I was surprised that the meeting should finish so early. — 會議竟然這麼早結束，我感到很意外。
5. 別和「應該」混淆

把兩種 should 分清楚：
- 建議／義務：You should call her.（你應該打電話給她。）這是在給建議。
- Section D 的反應用法：It is strange that he should call at midnight.（奇怪的是，他竟半夜打電話來。）這是在評論一件事，不是在要求他打電話。

快速檢查：看到 should 時，先看它前面是否有 strange, odd, funny, typical, natural, interesting, surprised, 或 surprising 等形容詞。如果是，再看 that 子句是否使用 should + 動詞原形；若符合，通常就是本課的反應用法。

Flashcards

Answer in your head, then reveal.

形容詞後的這種 should 用來表達什麼？

Show answer

在 strange、odd、funny、typical、natural、interesting、surprised、surprising 等評價或反應形容詞後的 that 子句中，should 可表達說話者覺得事情奇怪、意外、有趣或自然。

這個句型最常見的形式是什麼？

Show answer

It + be + adjective + that + 主詞 + should + 動詞原形。例：It is odd that she should know the answer.（奇怪的是她竟知道答案。）

should 後面的動詞要用什麼形式？

Show answer

should 後面接動詞原形：should be、should arrive、should know；不可寫成 should arrives。

It is strange that he should be late. 裡的 should 是「應該」嗎？

Show answer

這裡的 should 不表示義務或建議；它呈現說話者對 that 子句內容的反應。

如何用 typical 描述某人一貫的作風？

Show answer

It is typical of + 人 + that + 主詞 + should + 動詞原形。

主句是 was/were 時，that 子句裡的 should 要如何搭配？

Show answer

It was surprising that the bridge should survive. 主句用過去式仍可搭配 should + 原形；should 本身不必改成過去式。
