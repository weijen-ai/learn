從 aespa〈Whiplash〉學韓語：詞彙與文法

從 aespa〈Whiplash〉MV 裡的短韓語片語學詞彙、口語縮約與三個實用句型：-아/어도、-(으)ㄴ 채(로)、-(으)ㄹ 名詞修飾語。附自創例句、記憶卡和測驗，不重製完整歌詞。

2026-09-29 AI-assisted study guide, grounded in: aespa 에스파, “Whiplash” Official MV (YouTube)；Korean-English caption transcript；Korean Basic Dictionary 與韓語文法教學參考 · link

Learning objectives

  • 理解 MV 中數個常見韓語詞彙與短語。
  • 辨認口語非敬語形式，例如 집중해、넌、못 해。
  • 使用 -아/어도 表達「即使……也……」。
  • 理解 -(으)ㄴ 채(로)、-는 순간、-(으)ㄹ 名詞修飾語。
  • 分辨歌詞中的省略、縮約和韓英混用，避免照搬成正式書面語。

Explanation, step by step

1. 先認識素材：韓英交錯的歌詞

這支影片是 aespa 的〈Whiplash〉MV，片長約 3 分 10 秒。歌詞在英文與韓文間切換；本課只挑幾個很短的韓語片語來學，並補上自創例句，不是逐行翻譯整首歌。

練習時先聽出韓語片語的節奏，再看意思和文法。歌詞常用非敬語和省略形式，適合理解流行歌曲，但正式場合要改用敬語。

2. 抓住幾個有力的詞
  • 집중하다：專心、集中注意力。歌詞短語「집중해 좀 더」可以理解為「再專心一點」。집중해 是集中注意力的非敬語命令式； 좀 더 是「再多一點」。
  • 이유：理由、原因。
  • 이해하다：理解。口語中常把 이해하지 못해 簡化說成 이해 못 해，意思是「不能理解」。
  • 거침없다：毫不遲疑、俐落無阻。歌詞中的 거침없어 是非敬語現在式。

小提醒：넌 是 너는（你＋主題助詞）的口語縮約。這些形式帶有親近、直接的語氣，不適合直接拿去對長輩或陌生人說。

3. 文法一：-아/어도「即使……也……」

歌詞片語「무리해도」來自 무리하다（勉強自己、過度用力）＋ -아/어도（即使……也……）。另一個短語「외면해도」來自 외면하다（轉身不理、刻意避開）＋ -아/어도。

接法簡記：去掉詞典形 다，再依詞幹母音接 -아도 或 -어도；하다 動詞常變成 해도。例如：
- 바쁘다 → 바빠도：即使很忙
- 먹다 → 먹어도：即使吃
- 공부하다 → 공부해도：即使讀書

自創例句：비가 와도 갈 거예요.（即使下雨，我也會去。）這個句型表示後句不會因前面的條件而改變。

4. 文法二：保持狀態、某一瞬間

短語「흔들린 채」用到 -(으)ㄴ 채(로)，表示維持前面的狀態去做另一件事。自創例句：문을 연 채로 잤어요.（門開著就睡著了。）채 後面常接 로，也可以在某些語境中省略。

短語「시작되는 순간」包含 -는 순간，意思是「開始的那一刻」。自創例句：수업이 시작되는 순간 조용해졌어요.（課程開始的那一刻，大家安靜下來。）

5. 文法三：-(으)ㄹ 修飾後面的名詞

短語「이 판을 바꿀」中的 바꿀，是 바꾸다（改變）接 -(으)ㄹ 後用來修飾名詞，表示「會改變的／將要改變的」。例如：바꿀 계획（要改變的計畫）、만날 사람（要見的人）。

歌詞寫法「기횐」是「기회는」的口語／演唱縮約；正式書寫建議寫完整的 기회는。聽歌時辨認縮約很有用，但自己寫作時優先用標準拼寫。

6. 否定與語氣：-지 않다、-지

短語「외면해도 소용없지」裡，소용없다 是「沒有用、徒勞」；整個短語大意是「即使刻意不理也沒用」。結尾 -지 在這種非敬語語境中可帶有確認、加強語氣的感覺。

歌詞短語「사라지지 않아」使用 -지 않다 表否定，意思是「不會消失」。自創例句：그 기억은 쉽게 사라지지 않아요.（那段記憶不會輕易消失。）歌詞用 반말；加上 -아요/어요 就成為較有禮貌的說法。

7. 聽歌時的拆解方法

試著把片語拆成「詞幹＋文法＋語氣」，而不要逐字硬翻：
- 找出詞典形：외면해도 → 외면하다。
- 辨認文法：해도 → 하다 的 -아/어도 形式。
- 看句子關係：前半句讓步，後半句說結果仍然成立。
- 調整語域：歌詞中的非敬語可在學習時理解；日常禮貌表達要改用 -아요/어요 或合適的敬語。

自我練習：用 -아/어도 寫一句「即使累也會學韓語」；再用 -(으)ㄴ 채(로) 寫一句描述維持某個狀態做事。

좀 더 是什麼意思？

Show answer

「再多一點、再專心一點。」좀 是「稍微」，더 是「更、再」。

집중하다 的意思是什麼？

Show answer

集中注意力；歌詞中的「집중해」是對熟人使用的非敬語命令式。

-아/어도 表達什麼關係？

Show answer

即使……也……；動詞或形容詞詞幹接 -아/어도，例如 바쁘다 → 바빠도。

-(으)ㄴ 채(로) 的意思是什麼？

Show answer

在維持某種狀態的情況下；「문을 연 채로 잤어요」是「開著門睡著了」。

외면해도 소용없지 的大意是什麼？

Show answer

即使轉身不理也沒用；외면하다 是「無視、刻意避開」，소용없다 是「沒有用」。

이 판을 바꿀 中的 바꿀 是什麼文法？

Show answer

「會改變的／要改變的」；動詞詞幹 바꾸- 加 -(으)ㄹ 修飾後面的名詞。
